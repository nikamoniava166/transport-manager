# AGENTS.md — инструкция для моделей

Ты работаешь над игрой **«Менеджер перевозок»** — Telegram Mini App (экономический менеджер грузоперевозок с таймерами). Читай этот файл целиком перед изменениями: он описывает, что уже сделано, как устроен код, какие правила баланса и что делать дальше.

---

## 1. Что за проект

- **Игра:** владелец автопарка покупает грузовики, нанимает водителей, берёт заказы на бирже, выполняет рейсы в реальном времени, растит компанию (офис, прицепы, улучшения).
- **Платформа:** Telegram Mini App. Работает и как обычная веб-страница (для разработки).
- **Стек:** чистые HTML/CSS/JS без сборки. Никаких фреймворков, npm, bundler'ов — файлы открываются как есть.
- **Живой сайт:** https://nikamoniava166.github.io/transport-manager/
- **Бот:** [@RussianTruckManager_bot](https://t.me/RussianTruckManager_bot)
- **Мини-приложение:** https://t.me/RussianTruckManager_bot/RussianTruckManager
- **Язык интерфейса:** русский. Код и комментарии — тоже на русском, где это уместно.

## 2. Структура проекта

```
index.html              — точка входа (подключает Telegram SDK, шрифт Rubik, все скрипты)
css/styles.css          — вся тема (CSS-переменные), компоненты, анимации
js/data.js              — КОНСТАНТЫ: грузовики, прицепы, города, грузы, апгрейды, имена, levelInfo
js/state.js             — сейвы: defaultState, миграции, localStorage + Telegram CloudStorage
js/ui.js                — формат чисел, тосты, haptic+звук-хуки, тема, конфетти, updateHUD
js/sound.js             — синтезированные звуки (Web Audio, без файлов)
js/economy.js           — ЯДРО: заказы, рейсы, события, персонал, прицепы, гараж, офис, баланс
js/screens/home.js      — экран «Главная»
js/screens/market.js    — экран «Биржа»
js/screens/trips.js     — экран «Рейсы»
js/screens/garage.js    — экран «Автопарк» (машины + прицепы + дилер)
js/screens/salon.js     — экран «Салон» (грузовики б/у с пробегом)
js/screens/office.js    — экран «Офис» (финансы, персонал, найм, журнал операций)
js/screens/more.js      — экран «Ещё» (статистика, настройки)
js/app.js               — init, роутер navigate(), история «назад», тики
docs/game-design.md     — дизайн-документ (механики, таблицы, формулы) — источник правды по геймдизайну
docs/deploy.md          — инструкция по публикации (писал игрок)
README.md               — публикация и структура
cover-640x360.png       — обложка мини-приложения
```

**Порядок скриптов в index.html важен:** data → state → ui → sound → economy → screens → app. Экраны регистрируются в `Game.screens`, ядро — в `Game.economy`.

## 3. Как запускать и проверять

- Разработка: открой `index.html` в браузере (file:// работает) или `python -m http.server 8080`.
- После изменений перезагрузи страницу и проверь `window.__errors` (массив ошибок JS; должен быть пустым).
- Полезно в консоли: `Game.state`, `Game.economy.orderPay(190, 1.5, 1, false)`, `Game.navigate('garage')`.
- **Не пушь в GitHub без согласия игрока.** Договорённость: публикация на сайт — после согласования серии шагов. Локальный коммит после шага — можно и нужно.
- Пуш: `git push` (учётные данные уже в Git Credential Manager этого компьютера). Сайт обновляется ~1 минуту. На Android Telegram может держать старую версию — очистка кэша Telegram.

## 4. Что уже сделано (не переделывай без причины)

1. Каркас: 7 вкладок (Главная, Биржа, Рейсы, Автопарк, Салон, Офис, Ещё), тема Telegram (светлая/тёмная), Rubik, haptic, тосты, конфетти при новом уровне.
2. Экономика: биржа заказов (генерация по уровню/городу/грузоподъёмности/флагам), рейсы с таймерами и офлайн-прогрессом, события в пути (пробки, ДПС, поломки, бонусы), износ, топливо, авансы водителям.
3. Автопарк: 7 грузовиков (Газель → Scania), покупка, апгрейды (двигатель/ТО/расход), ремонт, расширение гаража.
4. Прицепы: 5 типов, покупка, крепление (1 на машину), флаги реф/ADR, износ и ремонт, надбавка к расходу.
5. Персонал: водители (доля с рейса, отдых, навыки), бухгалтеры (оклад + % к оплате, журнал операций), механики (снижение износа + авторемонт в час). Все занимают общие рабочие места офиса.
6. Офис: улучшение (+рабочие места), финансы, найм (кандидаты обновляются раз в 10 мин).
7. Гараж: улучшение (+2 места), лимит мест, блокировка покупки при полном гараже.
8. Уровни/XP, публикация (GitHub Pages + бот) — сделаны. Продажа машин, достижения (12 шт), ежедневные бонусы, графики финансов — **в плане, ещё не сделаны** (см. §5).
9. Публикация: GitHub Pages + бот + кнопка «Играть».
10. Салон б/у: 7-я вкладка; 3–5 предложений (износ 15–75 %, пробег, иногда апгрейды, «выгодные сделки»), завоз каждые 15 мин, покупка занимает место в гараже. Поле `img` у моделей в data.js — задел под картинки машин (сейчас заглушки 🚛); пробег копится за рейсы и виден в салоне/автопарке.

## 6. Правила и подводные камни

- **Сейвы:** ключ `tm_save_<telegram_id>` (или `tm_save_local` в браузере). Структура в `Game.defaultState()`. При добавлении полей — **обязательно** дописывай миграцию в `Game.migrate()` (старые сейвы игроков должны доливаться дефолтами). Не ломай `uid` существующих машин/водителей/прицепов.
- **`Game.state.uidSeq`** — сквозной счётчик id. Новые сущности берут id через `Game.uid()`.
- **Офлайн-прогресс:** `E.settle(silent)` при загрузке и каждый тик. Все таймеры — по меткам времени (`startedAt`/`endAt`/`restUntil`/`lastMaintAt`), ничего не «докручивай» setInterval'ами как источник истины.
- **Баланс:** не меняй формулы оплаты/опыта/времени без запроса игрока. Текущие (после ребаланса):
  - оплата: `(300 + км^0.92 × 28) × (0.75 + вес × 0.14) × множитель_груза × (срочный ? 1.4 : 1)`
  - время: `clamp(км / 50, 2, 25) мин × (срочный ? 0.75 : 1) × (1 − бонус скорости)`
  - XP: `округл(км / 20 + вес × 2)`; порог уровня 150, далее ×1.65
  - топливо: `км × расход/100 × 65 ₽ × (1 + надбавка прицепа)`
  - ремонт: `цена × 0.003 × износ%`
- **Константы баланса** — в `js/data.js` (fuelPrice, kmPerMin, minTripMin, maxTripMin, repairRate) и в `js/economy.js` (orderPay, tripMinutes, xpGain). GDD (`docs/game-design.md`) должен соответствовать коду — правь оба.
- **Тема:** только через CSS-переменные (`--bg`, `--panel`, `--accent`…). Не хардкодь цвета в стилях компонентов.
- **Звук:** только через `Game.sound.play(...)` / `Game.haptic(kind)` — он уважает настройки игрока.
- **Навигация:** только `Game.navigate('id')`. Экраны — объекты `{ render, onTick?, moneySensitive? }` в `Game.screens`.
- **Не используй** `alert`/`confirm` (в Telegram WebView ненадёжны) — двухшаговое подтверждение как у сброса прогресса.
- **Не добавляй** библиотеки и сборку без запроса игрока.
- **Язык ответов игроку:** русский.

## 7. Стиль кода

- ES5-совместимый синтаксис (function, var, без стрелок в ядре — экраны используют шаблонные строки).
- Тексты интерфейса — по-русски; числа через `Game.fmt`.
- Экран: `render(root)` строит HTML в `#screen`, навешивает `onclick` после innerHTML; `onTick` — для таймеров.
- Новые экраны: добавить `data-screen` в `index.html`, файл в `js/screens/`, скрипт перед `app.js`.

## 8. Формулы (быстрая шпаргалка)

```
оплата       = (300 + км^0.92 × 28) × (0.75 + вес × 0.14) × множитель_груза × (срочный ? 1.4 : 1)
время, мин   = clamp(км / 50, 2, 25) × (срочный ? 0.75 : 1) × (1 − бонус скорости)
XP           = округл(км / 20 + вес × 2); порог уровня 150, далее ×1.65
топливо, ₽   = км × расход/100 × 65 × (1 + надбавка прицепа)
аванс        = оплата × доля_водителя
ремонт       = цена × 0.003 × износ%
износ за рейс= min(8, 3 + км/500) × (1 − аккуратность×0.03) × (1 − скидка механиков) (+15 при поломке)
б/у салон   = цена нового × (0,65 − износ × 0,004, мин 0,18) + 35 % остатка апгрейдов; сделка −12 %
```

Полные таблицы машин/прицепов/городов/грузов — в `docs/game-design.md` и `js/data.js`.

## 9. Как проверить себя после изменений

1. Перезагрузить страницу → `window.__errors` пустой.
2. Пройти цикл: биржа → отправить рейс → подождать/ускорить (`trip.endAt = Date.now() - 1000` + тик) → деньги, XP, износ, журнал в «Офисе».
3. Перезагрузить страницу → сейв на месте.
4. Покликать все 6 вкладок.
5. Спросить игрока, что подправить, — и только потом следующий шаг.

---

**Коротко:** игра играбельна и опубликована. Дальше — контент (грузовики, города, продажа, графики, ачивки, бонусы), потом бэкенд (лидерборд, Stars). После каждого шага — пауза на правки игрока. Не пушь на сайт без его команды.
