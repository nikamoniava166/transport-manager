- одна строка маршрута: `📍 А → B · N км · ≈M мин · ⏳ K мин` (`.ocrd-sub`);
- «срочно ×1,4» и теги флагов переехали в заголовок; дублирующий тег «нужно ≥ X т грузоподъёмности» убран;
- кнопка мини: `.btn.mini` (`css/styles.css`), подпись «🚚 Отправить» вместо «Отправить машину»;
- класс карточки `.card.ocrd` — уменьшенные паддинги (8px 10px) и отступы (8px).
Цель достигнута: 5–9 заказов (все слоты) видны почти на одном экране.

**Партийный завоз** (`js/economy.js` → `refreshMarket`):
- новая метка времени `state.market.restockAt`: когда наступила — биржа дозаполняется до полного
  числа слотов (`E.marketSlots()`), затем `restockAt = now + rndInt(marketRestockMin..Max) минут`;
- `restockAt = 0` означает «завоз прямо сейчас» (первый запуск/старый сейв) — условие скипа:
  `if (s.market.restockAt && s.market.restockAt > now) return;`. ВАЖНО: первая версия условия
  `(!restockAt || restockAt > now)` была багом — при 0 биржа никогда не наполнялась. Не повторять;
- слот, освобождённый взятым заказом, больше НЕ заполняется мгновенно — ждёт ближайшего завоза;
- жизнь заказа сокращена с 10–30 до 6–14 минут (`expiresAt` в `generateOrder`), чтобы за цикл
  завоза реально истекало 1–3 заказа и партия была видна игроку.

**Константы** (`js/data.js`, блок «Биржа заказов: темп завоза»):
`marketRestockMin: 3`, `marketRestockMax: 5` (минуты между завозами), `orderLifeMin: 6`, `orderLifeMax: 14` (минуты жизни заказа).

**Таймер в шапке биржи** (`js/screens/market.js`): `<span id="restockTimer">` — «🕒 завоз через X»,
`onTick` обновляет только его текст (без перерисовки списка; при открытой панели выбора список не трогается).

**Миграция**: `defaultState.market = { orders: [], restockAt: 0 }` (было `refreshAt: 0`, поле переименовано;
старые сейвы получают `restockAt: 0` через `Object.assign` в `Game.migrate` — мгновенный первый завоз).

**Документы**: `docs/game-design.md` §5.1 (жизнь заказа 6–14 мин, завоз партиями, слоты) и таблица экранов;

## Как проверялось

1. `node --check` всех изменённых js — чисто.
2. Страница в браузере (file://): `window.__errors` пуст после навигации и тиков.
3. Полный цикл: биржа → `E.dispatch(uid, truckUid, driverUid)` → ускорение (`trip.endAt = Date.now() - 1000` + `E.settle(true)`) → деньги/XP/износ шин/усталость начислены, слот освободился и ждал завоза.
4. Взятие заказа оставляет дырку до завоза; принудительный `restockAt = 1` + тик добирает партию до 5 слотов.
5. Таймер тикает («3 мин 12 с») без перерисовки; все 6 вкладок + сегменты открываются без ошибок.
6. Перезагрузка — сейв на месте (деньги, 2 тестовых рейса, 990 км).

Примечание: при тесте «двойная» усталость/износ за один рейс оказалась артефактом отменённой
инструментальной попытки (скрипт успел исполниться дважды в странице) — в коде начисление одинарное (`economy.js` строка с `fatigueBase`).
