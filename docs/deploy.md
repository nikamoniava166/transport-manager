# Публикация «Менеджера перевозок» в Telegram Mini Apps

Игра — статический сайт (index.html + папки `css/`, `js/`, `docs/`), поэтому подойдёт любой бесплатный HTTPS-хостинг. Своего сервера и базы данных не нужно.

---

## Шаг 1. Хостинг (10–15 минут)

### Вариант А: GitHub Pages — рекомендую

Стабильный адрес, бесплатно, обновления простой загрузкой файлов.

1. Зарегистрируйся на **github.com** (если аккаунта нет).
2. Нажми **New repository** → имя `transport-manager` → Public → **Create repository**.
3. **Add file → Upload files** → перетащи в окно всё содержимое папки проекта: `index.html`, папку `css`, папку `js`, папку `docs` → **Commit changes**.
4. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты игра доступна по адресу `https://ИМЯ_АККАУНТА.github.io/transport-manager/`.

### Вариант Б: Netlify Drop — самый быстрый

1. Открой **app.netlify.com/drop** (нужен бесплатный аккаунт).
2. Перетащи папку проекта целиком в окно.
3. Мгновенно получишь адрес вида `https://случайное-имя.netlify.app` (имя можно сменить: Site settings → Change site name).

### Вариант В: свой хостинг/домен

Просто скопируй файлы в любую папку с HTTPS — больше ничего не требуется.

## Шаг 2. Бот и мини-приложение в @BotFather (5 минут)

1. Открой **@BotFather** в Telegram, отправь `/newbot`:
   - *Enter a name* → `Менеджер перевозок`
   - *Enter a username* → например `my_transport_bot` (обязательно заканчивается на `bot`)
2. Затем `/newapp`:
   - Выбери своего бота
   - *Short name* → `transport` (используется в ссылке)
   - *Description* → `Экономический менеджер грузоперевозок`
   - *Web App URL* → адрес с шага 1 (начинается с `https://`)
   - Фото можно пропустить или загрузить любое
3. На вопрос про **menu button** согласись (Set the menu button) — игра будет открываться кнопкой **Menu** в боте.
4. Готово. Прямая ссылка на игру: `https://t.me/ИМЯ_БОТА/transport`.

---

## Шаг 3. Проверка после публикации

Открой бота в Telegram → нажми кнопку **Menu** (или ↗) и проверь:

- [ ] Игра открывается на телефоне и в Telegram Desktop
- [ ] Тема подстраивается под светлую/тёмную тему Telegram
- [ ] Прогресс сохраняется после закрытия (localStorage)
- [ ] С другого устройства прогресс подтягивается (CloudStorage)
- [ ] Кнопка «Назад» в шапке Telegram возвращает на главный экран
- [ ] Вибрация (haptic) срабатывает на действиях

---

## Как обновлять игру

- **GitHub Pages**: Add file → Upload files → перетащи изменённые файлы → Commit. Сайт обновится через минуту.
- **Netlify**: вкладка **Deploys** → перетащи папку заново.
